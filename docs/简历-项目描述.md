# RAgent Router 简历项目描述

## 项目标题
RAgent Router —— 高并发 AI API 智能网关与容错引擎

## 技术栈
Go + Gin + GORM + Redis + SSE + SQLite + Docker 等。

## 项目职责

1. 设计三态熔断器（Closed→Open→HalfOpen），基于滑动时间窗口统计 Provider 失败率触发状态转换，每供应商独立维护熔断状态通过 Mutex 保证切换原子性，避免单点故障扩散；结合指数退避重试引入 Full/Equal/Decorrelated 三种 Jitter 策略降低惊群问题，通过 context deadline 实现级联超时控制。

2. 采用 FNV-64a 哈希分片 + Lazy Refill 策略实现高性能令牌桶限流，热路径 28ns/op，通过 Channel Semaphore 实现并发控制与舱壁隔离，多用户请求互不阻塞。

3. 实现三级渐进式路由引擎，关键词规则(0ms)→Embedding 语义匹配(~300ms)→LLM 意图分类(~500ms)→兜底，每层可独立禁用优雅降级；结合语义缓存（余弦相似度 0.92）缓存命中直接返回零 API 调用，TeeReader 捕获响应自动回填缓存。

4. 基于 ProviderAdapter 适配器模式抽象 Anthropic↔OpenAI 协议差异，设计双阶段上游请求（可重试连接+不可重试 SSE 流），通过 ErrStreamStarted 哨兵错误区分两阶段避免流中断后错误重试；Writer 装饰器实时解析 message_start/message_delta 事件提取 Token 用量。

5. 通过 Goroutine 编排多模型 Review 流程（DeepSeek 生成→Claude 审查），SSE 流注入 phase_change 事件实时反馈编排阶段，支持运行时动态指定生成与审查模型。

6. 基于 Pipeline 责任链模式实现 Prompt 复杂度分析等请求预处理，支持中间件热插拔；将核心类型提取为 internal/provider 独立包，通过接口抽象消除 proxy↔routing 循环依赖。
